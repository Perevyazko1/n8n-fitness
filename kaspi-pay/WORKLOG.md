# kaspi-pay — WORKLOG

Учёт трат во Вьетнаме по оплатам Kaspi QR (VND → списание KZT → пересчёт в RUB).
Данные берём со скриншота: iPhone «Команды» → OCR → POST на вебхук n8n.

## Что есть на сервере (проверено 2026-11-07)

- n8n 2.18.5, Public API включён (401 без ключа). Ключа у Claude нет, импорт JSON делает пользователь.
- Postgres 16 (`fitness-db`), credential в n8n — `PG`. Таблиц `kaspi_*`/`expense*` нет.
- LLM: credential `OpenAI account` уже есть. Anthropic credential нет.
- `/webhook/kaspi-expense` → 404 (пока не создан).
- RAM 2 ГБ, свободно около 950 МБ.

## План

1. SQL: `kaspi_expenses` (уникальный ключ дедупа) + `kaspi_fx_rates` (курс ЦБ на дату).
2. Воркфлоу приёма: Webhook + X-Token → 200 → LLM → валидация → курс → INSERT ON CONFLICT → Telegram.
3. Воркфлоу summary: GET `/webhook/expenses/summary` + проверка initData и user_id.
4. Mini App (HTML), подключение через BotFather.
5. Крон 21:00 Asia/Ho_Chi_Minh, итог дня.

## Что где лежит

- `sql/schema.sql` — `kaspi_expenses` (дедуп `dedup_key` UNIQUE) + `kaspi_fx_rates` (кэш курса ЦБ по дню).
- `Kaspi_Expense_Ingest.json` — приём: Webhook `POST /webhook/kaspi-expense` (Header Auth `X-Token`,
  200 сразу) → gpt-5-mini (structured outputs) → валидация → курс ЦБ (кэш на день по Москве) →
  INSERT ON CONFLICT → ответ в Telegram. chat_id в ноде `Config` (648226895, как в vocab-bot).

## Решения и грабли

- `ts` из «Команд» — локализованная строка iOS, не парсим: отдаём LLM как подсказку для «Сегодня/Вчера»
  и года. Опорное «сейчас» — серверное время в `Asia/Ho_Chi_Minh`.
- Пишем только `purchase` и `refund`; переводы/пополнения с экрана истории пропускаются.
- Дедуп: `минута|сумма ₸ (иначе ₫)|продавец без регистра и диакритики`. На экране истории времени
  может не быть → `time_known=false`, такая строка считается дублем при совпадении даты+суммы+продавца
  (в обе стороны). Риск: история может обрезать имя продавца — тогда дубль пролезет. Проверить на реальных скринах.
- Рубли: из ₸ по курсу ЦБ, если ₸ нет — из ₫. Если ЦБ не ответил — берётся последний кэшированный курс.

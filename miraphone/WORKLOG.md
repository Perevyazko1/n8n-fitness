### 3. Разведка тем: принцип и что работает

**Разведка ≠ поиск.** Поиск по запросу/хэштегу известной темы — это подтверждение, третий слой.
Разведка: не называем тему, наблюдаем популяцию, ловим аномалию. Пока гонял тематические
запросы («айфон», «ремонт»), система пропустила главный инфоповод недели.

Работает, проверено вживую:

1. **Панель + скорость.** YouTube RSS по списку каналов, `просмотры ÷ возраст` и `× медианы`.
   Прогон без единого запроса по теме → Канье вышел у ТРЁХ независимых каналов.
2. **Лента без запроса:** `news.google.com/rss?hl=ru&gl=RU&ceid=RU:ru` без `q=`.
3. **Совпадение по независимым источникам** — прокси спроса там, где нет счётчиков.
4. **Поиск по каналу:** `t.me/s/<канал>?q=<фраза>` — вся история с датами и просмотрами.
   Потолок ~20 сообщений, нужен запрос → это верификация, не разведка.

**Панель — главный актив.** Отбор фильтром «≥2 ролика за 14 дней И медиана ≥20k»: из 73
кандидатов прошло 22. Отсеиваются даже гиганты («Что было дальше?» с медианой 673k) — не
публикуют. Состав панели определяет, что система вообще способна увидеть.

### 4. Фильтр тем (правило клиента)

Политику, войну, катастрофы, преступления против людей и смерти — **не берём никогда**.
Проверять надо не тему, а **происхождение повода**: «маркетплейс не привезёт» — чистый
потребительский угол, но вырос из ударов БПЛА по складам, значит отклоняется.
На прогоне 24.08 фильтр убрал 2 темы из 6 и пометил ещё 2. **Половина горячего не годится —
это норма.** Нельзя требовать N тем в день: получишь натянутые.

### 5. Грабли

- **Окно `t.me/s/` ≈ 15 постов** — у быстрых каналов это 6–12 часов. Медиана свежего окна
  сравнивает пост сам с собой → выбросов не бывает В ПРИНЦИПЕ (разброс ×0,98–1,31).
  Без накопления ТГ-барометр не менее точен, а **не работает вообще**. Листается `?before=<id>`.
- **YouTube Trending мёртв** — страница отдаёт пустую сетку. Скорость только через поиск
  с фильтром `sp=EgQIAxAB` (за неделю); `sp=EgIQAg%3D%3D` — поиск каналов.
- **TikTok по России закрыт даже за деньги.** Акторы Apify «TikTok trends» — обёртки над
  Creative Center, в схеме `data_xplorer/tiktok-trends` 27 стран, **RU нет**.
- **Реакции набираются ~2 суток, просмотры идут дальше** — сравнивать посты честно можно
  только в одном возрасте либо повторными срезами.
- **Instagram Scraper:** `videoPlayCount` и `videoViewCount` различаются в разы (639k против
  107k) — выбрать одну метрику. `latestComments` = ~90 % объёма мусора. CDN-ссылки протухают.
- **Мем-фразы не ловятся ничем** из текущего («вот такая вот хуйня, собачка» — ноль совпадений
  в 126 роликах панели, 15 ТГ-каналах, 460 новостях). Нужен всплеск n-грамм по накопленному
  корпусу, и только по каналам, которые мемы **объясняют** словами (образец — `@mudak`),
  а не публикуют картинкой.
- **3DNews RSS** периодически отдаёт 403.

# WORKLOG — контент Рыжа (контент-холдинг)

Маскот Рыж продвигает фитнес-бота `@fitness_fox_bot` на трёх площадках. Они ведут друг в друга
по кольцу, а не по воронке в одну сторону:

| Площадка | Роль | Ритм | Ведёт в |
|---|---|---|---|
| ТГ-канал `@ryzh_trener` | польза: рецепты, замены, цены, разборы | пост в день | бот (в развязке, не в каждом посте), ролик |
| Instagram `@fitness_fox_bot` | эмоция и крючок: мем, лис, проблема | 2–3 ролика в неделю | канал (ссылка в шапке + стикер-ссылка в сторис) |
| Бот | продукт | — | канал (позже: анонс прицепом к утренней сводке) |

Ролики делаются в соседнем репо `../ryzh-promo` (Remotion, скилл `motion`).

---

## Стратегия (26.10.2026)

**Перекличка, а не повтор.** Одна тема — два слоя: ролик ставит проблему («ешь салат и не худеешь»),
пост её решает («салат на 350 ккал: состав и как не утопить его в соусе»). Текст ролика пост не копирует.
Ведёт канал: каждый день новая тема, а раз в неделю лучший пост становится темой ролика.

**Голос Рыжа** — из `../ryzh-promo/SCENARIOS.md`: питомец, жалуется и просит, не стыдит; сочувствие
вместо вины. **Рекомендации, а не экспертиза**: «я попробовал / можно так», без «учёные доказали»,
медицины, килограммов и сроков.

**Темы — из чужих выбросов.** Посты каналов-доноров старше 48 часов, обогнавшие медиану своего
канала в 1,5 раза по просмотрам или по доле реакций. Фактуру (граммы, цены, шаги) берём из текста
донора, пересказываем своими словами, чужой канал не упоминаем.

**Рецепты — да, но с крючком** (дёшево / за 10 минут / вместо X): голые рецептовые фермы дают ER 1,9 %.

**Сетка** (крон выбирает тему рубрики дня, если такая есть в очереди):
Пн «Рыж проверяет» (check) · Вт «Почём белок» (price) · Ср «Рецепт Рыжа» (recipe) · Чт «На глаз» (guess) ·
Пт «Рецепт Рыжа» (recipe) · Сб «Вместо этого» (swap) · Вс «Рыж пробует» (tried). Ещё есть «Лис» (fox) —
сценка, без своего дня. Старые myth/diary/qa больше не используются.

## Конвейер

```
07:00   Ryzh Scout       → /api/content/scout (Django): ленты доноров через t.me/s, снапшоты, выбросы
                          → gpt-5-mini: тема + рубрика + угол + фактура, отсев → ryzh_topics 'proposed'
10:00   Ryzh Post Draft  → тема (ручные queued → рубрика дня → сила выброса) → текст → картинка
                          → владельцу ОДНО сообщение: фото + подпись + кнопки
        Ryzh Post Control: ✅ опубликовать · ❌ отклонить · ◀️ Тема / Тема ▶️ · 🎨 Картинка · правка текстом
Вс 20:00 Ryzh Weekly Bridge → топ-3 поста недели своего канала → «тема недели для ролика»
```

| Файл | Что это |
|---|---|
| `Ryzh_Scout.json` | разведка: Django scout → LLM формулирует темы → `ryzh_topics` со статусом `proposed` |
| `Ryzh_Post_Draft.json` | черновик + картинка; вызывается кроном и из Control (другая тема / перерисовать) |
| `Ryzh_Post_Control.json` | бот-редактор `@ryzh_editor_bot`, кнопки и правки текстом |
| `Ryzh_Weekly_Bridge.json` | воскресная тема недели для ролика |
| `Content_Reels_Bot.json`, `Content_Reels_Bot_v2.json` | Reels-конвейер через n8n (v0 / stage 3a); основные ролики сейчас делаются в `../ryzh-promo` |
| `tests/Ryzh_*_Test.json` | TEMP-прогоны генерации кадров и клипов (Рилс #1) |
| `sql/schema.sql` | `reels_*`, `ryzh_topics`, `ryzh_posts`, `content_*` (всё идемпотентно) |
| `sql/holding_seed.sql` | 19 доноров + свой канал, редакторы, чистка висящих черновиков |
| `sql/ryzh_seed.sql`, `sql/ryzh_seed_02.sql` | ручные темы августа (`seed_02` — с фактурой, на сервер не применялся) |
| `backend/fitness/content.py` (корень репо) | парсер `t.me/s` и поиск выбросов |

**Статусы темы:** `queued` (руками, приоритет) · `proposed` (из разведки, живёт 14 дней) · `used` · `skipped`
(пролистнута кнопкой — крон её не берёт, листанием видна).
**Статусы поста:** `draft` · `posted` · `rejected` · `stale` (висел без разбора, снят чисткой).

**Редакторы** — таблица `ryzh_editors` (сейчас владелец `648226895` и `893232025`). Черновик приходит
каждому в личку; любой может опубликовать, отклонить, листать темы, перерисовать или поправить текстом.
После действия одного старая версия исчезает у всех (`ryzh_approvals` хранит, у кого какое сообщение),
о публикации обоим приходит «✅ #N опубликован · кто». Подсказки и «нет черновика» — тому, кто спросил;
«очередь пуста» и итог недели — всем. Новый редактор = `INSERT INTO ryzh_editors`, без переимпорта;
он должен хоть раз нажать /start у `@ryzh_editor_bot`, иначе Telegram не даст боту написать первым
(остальные редакторы черновик при этом всё равно получат).

**Картинка** — всегда AI: gpt-5-mini придумывает сцену, внешность Рыжа и стиль зашиты в
`Build Image Prompt`, рисует `gpt-image-1` (low, ≈ $0,01 за штуку, порядка 40–70 ₽ в месяц).
Тексты — gpt-5-mini, входит в бесплатную квоту OpenAI.

## Доноры (разведка 26.10.2026)

Метод: поиск каналов TGStat (14 ключевых слов + категория «Здоровье», через настоящий Chrome,
headless не пускает Cloudflare) → 377 каналов → замер через `t.me/s`: медиана просмотров постов
2–21 суток, ER = медиана ÷ подписчики. Живых (ER ≥ 5 %, ≥ 3 тыс., пост за 2 недели) — 142.
Отсеяны личные лайфстайл-блоги (выстреливает личная жизнь), врачи и БАДы, ПП-фермы на 300–400 тыс.
(охват 1–3 % от подписчиков). Итог — 19 доноров, список с цифрами в `sql/holding_seed.sql`.

- Рецепты и бюджет: Бюджетные рецепты, Даша — бюджетно (лучшая доля реакций, 7,1 %), sweetyzaika,
  0 калорий, С любовью ЗОЖ, Что на завтрак?, Салатом в лицо, Алия, Nastuzzzi.
- Разборы: ЖЖГИСЬ (ER 27,3 %, в августе было 20,5 %), Брин, BIOMACHINE, Food&Science, Калории и похудение, pro_appetit.
- Фитнес: Метаморфоза, Телега ЗОЖника.

## Как применить (делает пользователь)

1. Закоммитить, запушить → на сервере `git pull`, пересобрать api (новый эндпоинт `/api/content/scout`).
2. SQL:
   ```bash
   docker compose exec -T db psql -U fitness -d fitness < ryzh-content/sql/schema.sql
   docker compose exec -T db psql -U fitness -d fitness < ryzh-content/sql/holding_seed.sql
   ```
   По желанию — `sql/ryzh_seed_02.sql`: вернёт в очередь ручные темы августа с фактурой.
3. Импорт в n8n: `Ryzh_Post_Draft` (заменить), `Ryzh_Post_Control` (заменить), `Ryzh_Scout`, `Ryzh_Weekly_Bridge` (новые).
4. В Control в нодах **`Call Draft (nav)`** и **`Call Draft (redraw)`** выбрать воркфлоу «Ryzh Post Draft»
   (id меняется при импорте).
5. Второй редактор (`893232025`) — открыть `@ryzh_editor_bot` и нажать /start.
6. Проверить креды: Telegram «Ryzh Editor», Postgres «PG», OpenAI, header-auth «X-Cron-Secret».
7. Первый прогон руками: Ryzh Scout → в `ryzh_topics` появились `proposed` → Ryzh Post Draft →
   в личке фото с кнопками. Проверить «Тема ▶️», «🎨», правку текстом, «Опубликовать».
8. Активировать Scout, Draft, Control, Weekly Bridge.

# WORKLOG — контент Рыжа (контент-холдинг)

Маскот Рыж продвигает фитнес-бота `@fitness_fox_bot` на трёх площадках. Они ведут друг в друга
по кольцу, а не по воронке в одну сторону:

| Площадка | Роль | Ритм | Ведёт в |
|---|---|---|---|
| ТГ-канал `@ryzh_trener` | польза: рецепты, замены, цены, разборы | пост в день | бот (в развязке, не в каждом посте), ролик |
| Instagram `@fitness_fox_bot` | эмоция и крючок: мем, лис, проблема | 2–3 ролика в неделю | канал (ссылка в шапке + стикер-ссылка в сторис) |
| Бот | продукт | — | канал (позже: анонс прицепом к утренней сводке) |

Ролики делаются в соседнем репо `../ryzh-promo` (Remotion, скилл `motion`).

## Стратегия (26.10.2026)

**Перекличка, а не повтор.** Одна тема — два слоя: ролик ставит проблему («ешь салат и не худеешь»),
пост её решает («салат на 350 ккал: состав и как не утопить его в соусе»). Текст ролика пост не копирует.
Ведёт канал: каждый день новая тема, а раз в неделю лучший пост становится темой ролика.

**Голос Рыжа** — из `../ryzh-promo/SCENARIOS.md`: питомец, жалуется и просит, не стыдит; сочувствие
вместо вины. **Рекомендации, а не экспертиза**: «я попробовал / можно так», без «учёные доказали»,
медицины, килограммов и сроков.

**Темы — из чужих выбросов, от себя ничего не выдумываем** (решение владельца 31.10). Посты каналов-доноров
старше 48 часов, обогнавшие медиану своего канала в 1,5 раза по просмотрам или по доле реакций (посты про деньги
и замены — в 1,2 раза и в разбор первыми: цены есть только в 14 постах доноров из 688). Фактуру (граммы, цены,
шаги) берём из текста донора, пересказываем своими словами, чужой канал не упоминаем. Своего прайса и оценок
цен нет; единственная оценка — КБЖУ с «≈» (просьба владельца). Нет конкретики в доноре — нет темы.

**Направление** (31.10): только **деньги и замены** (`price`, `swap`) и **рецепты с крючком** (`recipe`).
Темы про поведение и привычки убраны совсем: из них выходила вода с советами как от эксперта (#28 «Чай со сладким»).

**Рецепты — да, но с крючком** (дёшево / за 10 минут / вместо X): голые рецептовые фермы дают ER 1,9 %.
Рецепт — это пост, а не карточка: хук → 2–3 предложения вступления от Рыжа → ингредиенты с граммовкой → шаги →
**строка КБЖУ** («≈ 320 ккал · Б 28 · Ж 14 · У 18» на порцию; из фактуры донора, иначе оценка по ингредиентам
с пометкой «≈») → совет → реплика 🦊. КБЖУ только после шагов, никогда в хуке (правки владельца 27.10).
Тон живой, телеграмный: восклицания, вопросы читателю, 5–9 эмодзи на пост (🛒 ингредиенты, 👨‍🍳 шаги, 📊 КБЖУ, 💡 совет).
Призыв к реакции («Сделаешь — ставь 🔥, не рискнёшь — 🙈») — примерно каждый третий день: флаг `cta` ставит нода `Topic`
(номер дня % 3). Реакции не накручиваем: доля реакций — наша же метрика для доноров и своего канала.
Реплика 🦊 — от первого лица и про этот пост; цитаты из роликов в промпте не даём, модель их копирует
(«он не ругается, он просит» в посте про гречку).
Подвал каждого поста собирает код (`Parse Draft`, `Parse Rewrite`), не модель: тег рубрики (`#рецепт_рыжа`,
`#почём_белок`…) + 1–2 тега темы от модели (последняя строка её ответа) + `📸 Рыж в Instagram` со ссылкой на
@fitness_fox_bot. При правке текстом подвал срезается до LLM и пришивается обратно. Текст — 600–800 знаков без подвала.
Модель лимит длины игнорирует (#22 вышел на 1242 знака, превью обрезалось на шагах — КБЖУ и теги не
было видно). Поэтому в Draft после `Parse Draft` стоит `Too Long?` (> 900 знаков без разметки) → `Shorten`
(gpt-5-mini, режет вступление/ингредиенты/шаги, КБЖУ, призыв и 🦊 сохраняет) → `Parse Short` с прежним подвалом.

Сетки по дням недели больше нет: она не работала (темы price/swap не приходили), а тему теперь выбирает редактор.

## Конвейер

```
07:00   Ryzh Scout        → /api/content/scout (Django): ленты доноров через t.me/s, снапшоты, выбросы
                           → gpt-5-mini: price/swap/recipe с фактурой, остальное в отсев → ryzh_topics 'proposed'
10:00   Ryzh Post Control → меню тем всем редакторам; /topics (или /темы) — в любой момент
                           [1…5] взять · [🗑] выкинуть · ◀️ ▶️ страницы
        выбрали тему      → Ryzh Post Draft: текст без картинки (бесплатно)
                           [🎨 Нравится, рисуй] · [📋 Другая тема] · [❌] · правка ответом
        🎨                → Ryzh Post Draft: картинка (≈ $0,06), фото + текст
                           [✅ Опубликовать] · [🎨 Перерисовать] · [❌] · правка ответом
Вс 20:00 Ryzh Weekly Bridge → топ-3 поста недели своего канала → «тема недели для ролика»
```

| Файл | Что это |
|---|---|
| `Ryzh_Scout.json` | разведка: Django scout → LLM формулирует темы → `ryzh_topics` со статусом `proposed` |
| `Ryzh_Post_Draft.json` | вызывается только из Control: `{topic_id}` — текст черновика, `{post_id}` — картинка |
| `Ryzh_Post_Control.json` | бот-редактор `@ryzh_editor_bot`: крон 10:00 и меню тем, кнопки, правки текстом |
| `Ryzh_Weekly_Bridge.json` | воскресная тема недели для ролика |
| `Ryzh_Image_API.json` | вебхук `POST /webhook/ryzh-image` для рилсмейкера `../ryzh-promo`: промпт (+ эталон-спрайт Рыжа или `none`) → PNG от gpt-image-2. Ключ — header-auth credential `Ryzh Image Key` (`X-Image-Key`), лимит 40 картинок в сутки (static data воркфлоу), ошибки OpenAI → JSON 502. Как звать — в `../ryzh-promo/CLAUDE.md` |
| `Content_Reels_Bot.json`, `Content_Reels_Bot_v2.json` | Reels-конвейер через n8n (v0 / stage 3a); основные ролики сейчас делаются в `../ryzh-promo` |
| `tests/Ryzh_*_Test.json` | TEMP-прогоны генерации кадров и клипов (Рилс #1) |
| `sql/schema.sql` | `reels_*`, `ryzh_topics`, `ryzh_posts`, `content_*` (всё идемпотентно) |
| `sql/holding_seed.sql` | 19 доноров + свой канал, редакторы, чистка висящих черновиков |
| `sql/ryzh_seed.sql`, `sql/ryzh_seed_02.sql` | ручные темы августа (`seed_02` — с фактурой, на сервер не применялся) |
| `backend/fitness/content.py` (корень репо) | парсер `t.me/s` и поиск выбросов |

**Статусы темы:** `queued` (руками, приоритет) · `proposed` (из разведки, живёт 14 дней) · `used` (взята в меню;
«Другая тема» возвращает в `proposed`) · `skipped` (выкинута 🗑, в меню не показывается).
Меню упорядочено так: `queued`, потом price/swap, потом сила выброса. У Telegram-ноды набор кнопок фиксирован, поэтому
пустые места занимает «·» (callback `pnop`). Взятие темы атомарно: двое нажали — черновик один; меню исчезает у всех
(`ryzh_menu_messages`). Слабое место: упал LLM при написании текста — тема уже `used`, вернуть её можно только в базе.
**Статусы поста:** `draft` · `posted` · `rejected` · `stale` (висел без разбора, снят чисткой).

**Редакторы** — таблица `ryzh_editors` (сейчас владелец `648226895` и `893232025`). Черновик приходит
каждому в личку; любой может опубликовать, отклонить, листать темы, перерисовать или поправить текстом.
После действия одного старая версия исчезает у всех (`ryzh_approvals` хранит, у кого какое сообщение),
о публикации обоим приходит «✅ #N опубликован · кто». Подсказки и «нет черновика» — тому, кто спросил;
«очередь пуста» и итог недели — всем. Новый редактор = `INSERT INTO ryzh_editors`, без переимпорта;
он должен хоть раз нажать /start у `@ryzh_editor_bot`, иначе Telegram не даст боту написать первым
(остальные редакторы черновик при этом всё равно получат).

**Картинка** — всегда AI и всегда **от эталона**: `Fetch Reference` тянет спрайт `fox_m2_b0.png` с GitHub Pages
Mini App, `Generate Ryzh` — gpt-image-2 в режиме edit (`gpt-image-1` к 26.10 API уже не принимает, хоть он и есть в списке; `input_fidelity` у gpt-image-2 нет), quality medium: «тот же персонаж,
новая сцена». По одному тексту модель рисовала чужого худого лиса в зелёной повязке (26.10, черновик #16).
Сцену (что делает и что держит) придумывает gpt-5-mini. ≈ $0,06 за картинку, порядка 150–250 ₽ в месяц.
Тексты — gpt-5-mini, входит в бесплатную квоту OpenAI.
